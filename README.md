# Sajt za turističku agenciju

Ovaj sajt je razvijen za izmišljenu turističku agenciju **ViaNexus** u okviru projektnog zadatka iz predmeta primenjene informacione tehnologije.

## Opis

Sajt je jednostavnog, minimalističkog dizajna. Posetioci se mogu upoznati sa više aranžmana (letovanja, evropski gradovi i daleke destinacije), pretražiti aranžmana preko jednostavnog polja za pretragu, "poslati" poruku preko kontakt forme i videti lokaciju agencije preko *Google Maps i-frame*-a.

### Tehnologije primenjene pri izradi projektnog zadatka

* HTML5
* CSS3
* JavaScript
* Bootstrap 5
